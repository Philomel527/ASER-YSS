# 已核实的 AStoryX 工作流程

核对基线：YSS 源码提交 `49e2528c42809779d046664373946378a8e04ac6`。其版本头标为 **0.18.0.255 EA TP1**，内含 ASER **3.0** 和 **3.6.7** 项目模板。这三个版本概念不可混用；模板版本不证明用户的 ASER 本体版本。

本文依据已下载的上游 README、诊断文档、解析器、规则 JSON、中文参数说明和官方示例。语雀教程全文及用户的 ASER 本体尚不可读，本文不声称已经完成播放验证。

## 角色与文件流转

**YSS 是编辑器，ASER 是播放引擎，脚本语言是 AStoryX。** 不需要把剧本转换成 C++ 或 Python 来播放；我们交付的是 `.astoryx` 文本。YSS 的 ASERStudio 插件按项目规则提供着色、补全、诊断和调试入口，ASER 根据脚本、规则和资源执行剧情。

```mermaid
flowchart LR
  A[用户剧本与演出规定] --> B[story-code 中的 AStoryX 文本]
  B --> C[目标 ASER 项目的 Stories 目录]
  D[Rules 与当前素材目录名单] --> E[YSS 检查]
  C --> E
  E --> F[ASER 播放验证]
  F --> G[按用户要求修正演出]
```

`story-code/` 是交付源码的专用目录，只放根据用户剧本编写的代码。使用时，将相应文件复制到目标 ASER 项目的 `Stories/`，并使用该项目的 `Rules/`、`Resources/` 和 `Configs/`。YSS 的工作区文件是 `project.yssp`；不能把普通目录或只含文本的 `story-code/` 当作已配置完整的 ASER 项目。

## 文本与语法

- 使用 UTF-8 文本和 `.astoryx` 后缀。上游文本读写明确使用 UTF-8；目前未验证其他编码。交付时默认 UTF-8 无 BOM。
- **第一行是简介，按注释处理，不执行剧情。** 在后面的靠前位置选择规则，例如 `#useRule:AdvanceRule`；官方新版示例另写 `#version:2`。这里的 `2` 不是 ASER 软件版本。
- 默认规则的控制器行首包含中文全角冒号，如 `背景：`、`音乐：`、`遮罩：`；角色使用 `--`，延迟使用 `+`。
- 对话没有独立行首标识。说话人与台词之间使用真正的 **Tab 字符**，不是空格，也不是字面量反斜杠加 `t`。
- `BaseRule` 多数可选参数按 `/` 的位置填写；`AdvanceRule` 多数使用 `,@参数名=值`。默认优先采用后者，但必须与目标项目规则一致。**变量赋值是例外，仍为 `变量：名称=表达式`。**
- `//` 是行注释。不要把任意以 `#` 开头的文字当作注释；它可能被当成预处理器指令。
- `&{...}`、`$[变量名]` 和 `$(块参数名)`在解析时受到特殊处理。不要用其他语言的引号或反斜杠规则代替它们；遇到分隔符与富文本标签冲突时对照工具示例处理。
- 控制器行首写错时，文本可能被回退解释成对话，而不是报出“未知指令”；没有报错不代表演出正确。

两套规则各有 **21 类控制器**。完整参数、前缀、默认元数据及约束见 [控制器参数参考](astoryx-controller-reference.md)。

## 演出与对白

- `遮罩：true` 开启对白区域；官方基础示例明确说明遮罩关闭时对白内容不显示。按用户的镜头要求安排开关。
- **`*` 开头的 Narration 是阅读／对话记录提示，普通播放时不显示。** 需要观众看到的独白应采用适当的对话或自由文本形式。
- `SlotIndex` 用于区分同时驻场的角色、音乐或文本；不能让多个需要并存的对象误占同一插槽。
- `IsBlocker` 会影响后续控制器的等待和并行关系；它不是整段剧情的统一开关。`+秒数` 是显式延迟。
- 时间类参数以秒计。立绘的 `FadeOutTime=0` 在官方示例中表示持续驻场，直到后续同插槽控制器改变它。
- `StartPosition`、`EndPosition` 是向量；向量维数、音量范围、曲线枚举等以对应参数元数据为准，不能笼统套用同一规则。
- `#aliases` 与 `#endaliases` 围成素材名到发言别名的映射区域。官方示例用 `mon3tr(amb2026)->Mon3tr/？？？`，使对应发言名关联立绘高亮。
- 关于音乐的 `FadeInTime`，官方基础示例解释为淡出上一首音乐，而中文参数提示只写“淡入”。这是需要在目标 ASER 版本中复核的行为差异，不能只凭参数名承诺效果。

## 变量、选项和复用

官方第二个基础示例同时覆盖以下功能：

- `#block 名称(参数)`、`#endblock` 定义复用块；`#use 名称(值)` 调用；块内使用 `$(参数)`。
- `变量：名称=表达式` 赋值；显示文本中使用 `$[名称]` 引用值。
- `选项：` 的选项内容按规则使用反引号分隔；`OutputVariable` 保存从 **0** 开始的选择编号。
- `判断：` 将各表达式大于 0 的结果组成位标记；不是常见编程语言的 `if` 语句。
- `标记：` 声明落点，`分支：` 根据变量及落点列表跳转。官方示例用 `分支：_,@Branches=落点` 实现无条件跳转。
- 官方示例特别说明变量运算在自动播放模式执行；阅读模式或调试跳转不能等价替代对分支逻辑的正常播放测试。

## 素材与目录名单

当前快照带有基础示例所用的一张背景、Mon3tr 普通立绘、阿米娅 Spine 立绘、音乐、音效和特效等，**不是完整官方素材库**。部分示例明确要求官方素材连接。

YSS 创建 3.6.7 项目时还会重命名部分文件：例如 `MagneticBurst.wav` 复制为 `磁爆.wav`，`Amiya(furnace_finale)` 的相关路径改为 `阿米娅(furnace_finale)`。因此源码模板中的原始路径、生成项目的路径和脚本引用不能混为一谈；应按 `ASERProjectTemplate.cpp` 的文件映射生成项目或在 YSS 中新建项目。

资源监视器读取的官方目录资料包括：

- `Configs/officialAssets_collections.json`：资源集合索引。
- `Configs/officialAssets_aliases.json`：官方资源别名。
- `Configs/officialAssets_userConfigs.json`：角色差分等配置。

源码还读取 Windows 本地数据路径 `AppData/LocalLow/Gradus/ASE-Remake`。这类资料不一定跟播放器安装目录放在一起。项目模板中的 `override_aliases.json`、`override_userConfigs.json` 也不能当成完整官方名单。

新增剧情只引用已在用户当前资源名单或项目自带资源中核实的标识；资源缺失时先记录并询问素材选择，不猜名字替代。
