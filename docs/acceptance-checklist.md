# 本地剧情验收

这是一份按本次要求创作的技术验收剧情，不是正式二创故事。目标播放器为你提供的 ASER 3.7.12；规则来自指定 YSS 提交的 3.6.7 项目模板。角色、背景和特效已随项目带齐，另附新生成的 A/B/C/D 校准图和检测音，不要求先连接官方素材库。

## 打开方法

1. 完整解压 ASER_YSS_acceptance.zip，保留 Resources、Rules、Stories、Configs 的相对位置。
2. 在 ASER 的剧本集页面打开 ASER_YSS_Acceptance 文件夹；或在 YSS 0.17 及之后版本打开其中的 project.yssp，并将 ASER 程序路径指向你的 ASE-Remake.exe。
3. 首先从头正常播放 00_all_features，再播放 01_base_rule。变量和分支请不要只靠调试拖动验证。
4. 最后逐个播放 02–10 的边界剧情。它们与主剧本独立，便于定位文档和具体版本的差异。

主剧情含一次交互选择，选任意一项即可；想检查其他选项可以重播。图形、特效和音效持续时间较短，可在确认加载成功后使用调试面板暂停观察。

## BaseRule

01_base_rule 复核同一套 21 类控制器在位置语法下的使用，同时检查中间留空、尾项省略、真正的 Tab、正文斜杠保护、等号赋值、分号判断、默认 choice 变量及无条件汇合。终点为 B_DONE。

## 独立边界剧情

这些文件负责核实确实存在资料差异的格式。结果与普通主剧情分别报告；不能因为主剧情通过，就把这些项目也记为通过。

| 文件 | 目的与记录方式 |
| --- | --- |
| 02_default_values | D01 比较默认拼接列数与显式 2；D02 比较省略 StayTime 和显式 0；D03 比较默认自由文本层级与显式 0／1000。记录观察结果。 |
| 03_character_curve_2 | 语雀描述的两项位置／旋转曲线。观察是否正常移动、旋转，或报告诊断。 |
| 04_character_curve_4 | 语雀描述的四轴曲线。观察各轴与旋转，或报告诊断。 |
| 05_character_curve_3 | 固定 YSS 元数据允许的三项曲线格式。与前两个文件分别记录。 |
| 06_float_branch | 依次显示九个输入的实际落点。记录 1 与 2 的整点、整点两侧、负数与大值的表现。 |
| 07_protection_and_bool | P01 普通变量引用、P02 保护文段内变量引用；比较两者显示；P03 复核数字 0／1 布尔格式。 |
| 08_music_null | 复核上游第三个示例出现的 null 停止标记，记录是否停止或报缺失资源。 |
| 09_curve_unset | Unset 为元数据里的保留枚举；记录默认曲线／移动或诊断的实际表现。 |
| 10_spine_skin | 复核 default;Idle 的皮肤与差分组合。default 皮肤和 Idle 动画已从实际骨架解析确认。 |

## 反馈格式

请按以下格式反馈异常，便于直接定位并修改：

- 文件名与检查编号，例如 00_all_features / M14V。
- 实际出现的画面、文字、声音或原始报错；必要时附截图。
- 是否在从头正常播放时复现，还是只在调试跳转时发生。

本地反馈前的检查范围是文本结构、规则参数、资源引用、宏和标签、实际音频时长及素材解析；ASER/YSS 图形界面的播放结果仍待你这次验收。本项目不声称穷尽所有自定义规则、任意第三方插件或每种素材组合。
