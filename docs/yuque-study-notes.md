## 对此前笔记的校正与补充

1. **规则声明固定在第二行。** 第一行为显示在剧本列表中的简介；第二行写 `#useRule:AdvanceRule` 或当前项目实际规则，第三行默认写 `#version:2`。此前“放在后续靠前位置”的表述不够严格，已修正。
2. **预处理、播放逻辑分别处理。** 别名与块在播放准备阶段处理；`#use` 是宏展开，不是运行时跳转或函数调用。块应先声明，再使用；`$(参数)` 与播放变量 `$[变量]` 不可混用。
3. **参数前缀决定语法。** `/` 在 BaseRule 中表现为位置分隔符，底层实际是各参数的识别前缀。独一性成立时前缀互不相同，因此 AdvanceRule 可省去不用的参数，并改变具名参数的次序；变量赋值仍使用 `=`。
4. **屏幕旁白使用无名对话。** 单独一行台词正文可表示不显示说话人名称的对话；`*` 的 Narration 只出现在阅读记录中。说话人与台词仍须使用真正的 Tab 分隔。
5. **关闭遮罩不等于清除旧台词。** 遮罩关闭后对白只是隐藏，再开启时可能重新显示旧内容。需要清除时可按教程写一行 `<br>`。
6. **文本保护和富文本配合。** `&{...}` 将文本保护为整体，可避免正文中的 `/` 等符号被当作语法。富文本结束标签也可能含 `/`。`<br>` 是单独标签；嵌套标签反向闭合。ASER 的 `<b>` 不按普通加粗处理，不能将常见 TMP 效果全盘套用。
7. **单人／双人槽位要显式清理。** 槽 0 默认居中，1、2 分别偏左、偏右，横坐标通常为 -2.15 与 2.15；其他槽默认居中。切换布局前清除不再使用的槽，避免残留立绘。
8. **Z 轴和遮挡优先级分别控制。** Z 改变距离和视觉大小，`RenderOrder` 控制遮挡。发言关联可能将非发言者的渲染顺序降低 100，应把这一偏移纳入分镜设计。
9. **音乐淡入参数的实际约定。** 参数文档与官方示例均说明 Music 的 `FadeInTime` 作用于上一段音乐的音量渐降，不能只按名字解释为新音乐淡入。带前奏的外部音乐按 `_intro` 与 `_loop` 成对命名，脚本引用共同主名。
10. **分支不会自动互斥。** 标记只提供落点，执行完一个分支后仍可能顺序进入下一个；互斥片段末尾要跳往共同结束标记。`_` 保留用于无条件跳转，不拿来存选项结果。选项编号从 0 开始。
11. **调试拖动不代替逻辑测试。** 变量、选项和分支要从头按正常播放验证；调试进度跳转得到的变量状态可能不同。调试面板中的临时参数调整也不会自动写回剧本。
12. **官方别名与剧本别名不同。** 官方资源别名可以用于引用素材；剧本 `#aliases` 用于让发言名关联已显示的立绘。第三章的一处箭头方向文字与其示例相反；本项目依据前后示例及源码说明采用 `素材名->发言别名`。

## 文档与固定源码存在的差异

这些是资料层面的差异，没有被当作已复现的运行时缺陷。生成的参数参考仍准确标明其来源是 YSS 的固定源码元数据。

| 项目 | 已观察到的资料差异 | 实现时的处理 |
| --- | --- | --- |
| 背景 `StitchColumnCount` | YSS 元数据默认 1；语雀参数文档默认 2147483647。 | 需要拼接时明确填写所需列数，不依赖隐式默认值。 |
| 角色 `StayTime` | YSS 元数据默认 1.75；语雀参数文档默认 0。 | 对影响节奏的停留时间显式赋值，并以目标本体播放结果为准。 |
| 自由文本 `RenderOrder` | YSS 元数据默认 0；语雀参数文档默认 1000。 | 需要确定遮挡时显式指定层级。 |
| 角色 `MoveCurve` 维数 | YSS 元数据允许 1 或 3 项；语雀参数文档另描述位置／旋转及四维控制。 | 默认使用单一曲线；需要分轴或旋转曲线时单独验证。 |
| 判断的多表达式分隔 | 第七章部分文字用逗号；参数文档及新版官方示例用分号。 | 默认依据参数文档和新版示例使用分号。 |
| 分支的浮点边界 | 第七章的范围叙述与参数文档的向下取整说明不一致。 | 常规选项分支使用整数；必须依赖浮点边界时先做目标本体验证。 |
| 曲线拼写 | 教学文字部分使用 `Liner`，参数表、枚举及曲线图片用 `Linear`。 | 使用已在规则元数据中核实的 `Linear`。 |

## 资源连接与本地运行

教程的默认打包位置是 `YSS/user_data/third_party/ASE-Remake/ASE-Remake.exe`；也可在 YSS 设置中手动指定程序路径。本仓库保持用户要求的 `vendor/ASER/` 位置，不额外复制一份本体。

官方素材来自本地明日方舟 PC 客户端。客户端需至少正常启动并成功登录一次，再在 ASER 选择游戏安装目录、导入与游戏版本匹配的收录名册。`collections`、`aliases`、`userConfigs` 是不同类型的文件，不能导入错位。

这次播放器包只含程序与运行库，没有项目的 `Rules/`、`Stories/`、外部 `Resources/` 或完整的 `officialAssets_*.json` 名单。已有 YSS 模板可作为项目起点，但不能据此假定所有官方素材可用。需要指定官方素材时，仍须取得用户当前的收录名册、别名和差分配置。

后续用户已单独上传 `Configs.rar`，其中三份名册、别名和差分配置现保存在 `resource-catalog/Configs/`，当前可以据此定位用户设定的名称。详见 [资源名册与别名](resource-catalog.md)；上述播放器包的内容结论不变，配置来自这次补充上传。

YSS 调试自动播放要求 ASER 至少 3.5、YSS 至少 0.15，并选择调试运行；不调试运行通常只打开播放器。先关闭另一个手工启动的 ASER 实例，可避免进程冲突。
